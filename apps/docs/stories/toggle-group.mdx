# ToggleGroup

A set of two-state buttons that can be toggled on or off, in single or multiple selection mode.

For the quick-start preset, see [ToggleGroupSimple](?path=/docs/composed-components-togglegroupsimple--docs).

## Basic usage (composition)

For full control over each option, use `ToggleGroup` with `ToggleGroupItem` as children:

```tsx
import { ToggleGroup, ToggleGroupItem } from '@signozhq/ui';
import { AlignLeft, AlignCenter, AlignRight } from '@signozhq/icons';

export default function MyComponent() {
	return (
		<ToggleGroup type="single" defaultValue="center">
			<ToggleGroupItem value="left" aria-label="Align left">
				<AlignLeft style={{ width: '0.75rem', height: '0.75rem' }} />
			</ToggleGroupItem>
			<ToggleGroupItem value="center" aria-label="Align center">
				<AlignCenter style={{ width: '0.75rem', height: '0.75rem' }} />
			</ToggleGroupItem>
			<ToggleGroupItem value="right" aria-label="Align right">
				<AlignRight style={{ width: '0.75rem', height: '0.75rem' }} />
			</ToggleGroupItem>
		</ToggleGroup>
	);
}
```

For multiple selection:

```tsx
<ToggleGroup type="multiple" defaultValue={['bold']}>
	<ToggleGroupItem value="bold" aria-label="Bold">
		<Bold style={{ width: '0.75rem', height: '0.75rem' }} />
	</ToggleGroupItem>
	<ToggleGroupItem value="italic" aria-label="Italic">
		<Italic style={{ width: '0.75rem', height: '0.75rem' }} />
	</ToggleGroupItem>
</ToggleGroup>
```
